# EaseTalk — Anonymous Support Platform (Educational Project)

**EaseTalk** is a web-based anonymous support and messaging platform built to demonstrate privacy-focused communication between users and service providers. The project focuses on anonymity, role-based access, and secure backend design.

---

## 🌟 Features

- Anonymous user registration (no personal information required)
- Service provider profiles
- Private one-to-one messaging
- Role-based access control
- Privacy-first backend architecture
- Responsive design

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Backend | Python, Django |
| Frontend | HTML, CSS, JavaScript |
| Database | MySQL |
| Media Storage | Local file system |
