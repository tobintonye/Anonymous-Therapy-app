EaseTalk — Anonymous Therapy Platform

**EaseTalk** is a web-based anonymous therapy platform that connects users with therapists in a safe, confidential environment. Users can browse therapies, communicate anonymously, and access mental health support without revealing their identity.

## 🌟 Features

✔ **Anonymous user registration** - No personal information required  
✔ **Therapist profiles** - Browse and select from therapists  
✔ **Secure messaging** - Confidential communication between users and therapists  
✔ **Messaging** - Message therapist anonymously
✔ **User anonymity protection** - Privacy-first architecture  
✔ **Responsive design** - Works on desktop and mobile devices

🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Backend | Python, Django |
| Frontend | HTML, CSS, JavaScript |
| Database | Mysql |
| Media Storage | Local file system |

## 🚨 Important Note

This application deals with sensitive mental health information. Please ensure:
- Compliance with HIPAA/healthcare regulations if deploying for real use
- Proper encryption for data at rest and in transit
- Secure hosting environment
- Professional review of privacy and security measures

**This project is for educational/portfolio purposes and should not be used for actual therapy services without proper legal and security reviews.**
